Thirty-nine ways the brand could look.

Each of these is a full, working homepage — not a mockup. Same brand, same products, thirty-nine completely different personalities. Batch A (01–07) varies the visual style. Batches B, C and D (08–32) vary the page structure — a catalogue, an FAQ, a letter, a diagram, a manifesto, a type specimen, a bento dashboard — so they differ in what the page actually does, not only how it looks. Batch D also adds the four commerce pages the set was missing: a product page, a shop grid, a checkout and a visit page. Batch E (33–39) is built for the new name, Hot Ice Jewels — every page takes a position on the hot/cold axis inside the name: ice is made with fire. Batches A–D were designed under the earlier working names and still carry them.

Design prototypes. Every price, product, statistic, quote and name is placeholder content written to make the layouts judgeable — none of it is a real offer, a real review, or a real person.

How to use these

Don't try to pick a winner on the first pass. Sort them into three piles instead.

  1. Gut reaction. Open all seven, spend thirty seconds each, and note which two or three you'd actually want your name on. Ignore the details.
  2. Audience check. Of those, ask which one your customer would trust with $4,000. Flash sells attention; restraint sells price.
  3. Pick a style and a structure separately. That's what the two batches are for. Vault's typography on Anatomy's diagram structure is a real option, as is Miami's palette on the Ledger's stock-list shape. Name the combination and I'll build it.
